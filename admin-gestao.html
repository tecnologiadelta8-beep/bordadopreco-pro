Cadastrar Software

1. Produto e pagamento

Nome, valor e como o cliente paga. O restante (foto, o que faz, instalador) vem nos blocos seguintes.

Formas de pagamento (aparecem em “Quero comprar”)
PIX e cartão apenas. O cliente paga, envia HWID + comprovante e aguarda a chave de liberação.

2. LEIA-ME / Apresentação do programa

Carregue o LEIA-ME nativo do programa (.txt / .md). O sistema limpa e organiza automaticamente (remove cabeçalhos, copyright, traços etc.) e monta a seção “Como funciona” da página do produto. Você ainda pode revisar e ajustar o texto antes de salvar.

Dica: use ## Título e ### Subtítulo para organizar seções. O site renderiza isso automaticamente.

3. Foto do produto (card + página)

Envie a imagem (vai para o Cloudflare R2) ou cole o link público.

4. Arquivo do programa (.zip recomendado) — opcional

Prefira .zip. O arquivo é enviado automaticamente para o Cloudflare R2 (ou cole a URL pública se já tiver).
